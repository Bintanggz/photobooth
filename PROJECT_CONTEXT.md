# PROJECT CONTEXT

## PRODUK
Web photobooth gratis untuk mahasiswa Indonesia, bertema tren (Y2K, Korean life4cuts, retro film strip, tema kampus). Tidak perlu akun.

## ALUR PENGGUNA
Pilih tema dan filter -> tekan Mulai -> 4 foto dengan countdown 3 detik -> pilih frame, filter, stiker -> unduh atau bagikan.

## STACK
React + Vite + Tailwind CSS, HTML5 Canvas, tanpa backend.

## DUKUNGAN PERANGKAT
- HP (360-430px), tablet/iPad portrait dan landscape (768-1180px), laptop/desktop (1280px ke atas).
- Browser: Chrome, Safari (iOS/iPadOS/macOS), Edge, Firefox versi terbaru.
- Sentuhan, mouse, dan keyboard harus sama-sama berfungsi.
- Tidak boleh ada fitur yang hanya jalan di satu jenis perangkat. Jika ada keterbatasan, sediakan fallback.

## ATURAN
- Semua proses foto client-side. Foto tidak boleh diunggah ke server mana pun.
- Tema berbasis data: satu tema = satu file JSON, bukan hardcode.
- Jangan pakai aset berhak cipta (karakter, logo, font berlisensi komersial, teks atau gambar dari situs lain).
- Jangan menambah dependency baru tanpa menyebut alasannya dan meminta persetujuan pengguna.
- Kode sederhana, komentar singkat dalam bahasa Indonesia.
- Semua teks antarmuka dalam bahasa Indonesia yang natural.
